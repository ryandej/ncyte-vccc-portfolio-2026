# NCyTE VCCC Portfolio 2026

## Project Overview

This repository documents my work from the 2026 NCyTE Virtual Cybersecurity Career Challenge. The challenge involved building, validating, securing, and documenting an enterprise-style network environment using segmented infrastructure, multiple operating systems, security controls, and service components.

The environment included a WAN segment, DMZ/screened subnet, firewall core, transit network, internal LAN, Windows and Linux systems, Active Directory/DNS services, web and database infrastructure, monitoring components, and secure administrative access paths.

## My Role

My primary role focused on cybersecurity infrastructure engineering, network security validation, systems hardening, technical documentation, and security assessment support.

I contributed across several areas of the project, including:

* Enterprise network topology design and documentation
* Proxmox virtual network mapping and VM placement validation
* Routing and traffic-flow troubleshooting
* Firewall and NAT validation
* Secure administrative access using a management host and SSH key-based authentication
* Windows and Linux system baseline collection
* AD/DNS, workstation, database, and service validation
* Security hardening and change tracking
* Audit table development and remediation documentation
* Red Team assessment review and After Action Report support
* AI/security workflow design and local AI agent validation
